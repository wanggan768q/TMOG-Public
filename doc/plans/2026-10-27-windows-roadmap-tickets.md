# TMOG Windows 完整后续路线与 Issue 拆分草案

日期：2026-10-27。状态：36个议题已创建为 #5—#40，69条GitHub原生依赖已逐项读取验证，无API错误。完整编号、链接与执行顺序见 `2026-10-27-windows-issues-index.md`。范围：Windows优先；Linux／macOS仅记录暂缓。

## 背景、已有成果与边界

- #1 已关闭：Windows 11 x64 Processes 首版、真实进程 CPU／驻留内存、排序、暂停刷新、选择保持、安全结束和人工验收已完成，不重复建立这些任务。
- #2 仍开放：macOS／Linux 适配。保留原议题，不关闭、不修改、不建立跨平台重复任务，也不作为任何 Windows 议题的阻塞。
- 当前 C++20／Qt Widgets／CMake 实现继续复用，不改写成 Win32，也不预建后台服务、插件、数据库或新的商业授权体系。
- 原官网 Windows UI 为 C++／Win32；本项目为独立 Qt 实现，不承诺像素级一致或原厂文件格式兼容。
- 原版行为没有证据时，明确标为新实现合同；不能以授权审计、官网宣传或空页面证明功能等价。
- 不复制厂商身份、密钥、许可协议，不连接厂商授权或遥测服务；不在包中带原厂 EXE／抓包。不会默认启用升级检查或自动下载。
- 遥测的零值、待采样、不可用和采样中断必须区分；系统汇总不能通过进程求和代替，缺失传感器不估算成真实功耗。
- 危险操作必须确认、身份绑定、权限失败处理；不默认提权、不绕过保护、不用真实关键系统对象做破坏性测试。
- 每项实施任务均包含可运行行为检查、实际 UI 路径和失败状态；不能仅凭构建成功关闭功能任务。Release 检查必须有效。

## 每个 Issue 的实现边界与验收补充

### W01、W32—W35：首轮安全与可信验证收尾
- W01核心检查在 Debug、Release都执行；人为构造错误必须非零退出，不能被NDEBUG消除。身份不匹配拒绝使用受控子进程，错创建时间必须返回IdentityChanged并验证子进程仍存活，不能因随便枚举到不可用PID而跳过。关键性拒绝通过受控检查验证，不实际调用真实csrss等关键对象的终止路径；失败也清理测试子进程。
- W32模态确认框前按值冻结目标信息，后台替换模型不得使确认后的身份成为悬空引用；跨刷新／排序／目标退出确认仍绑定最初目标，取消零操作。继续复用原安全终止路径，不扩大权限。
- W33窗口／枚举器必须在线程确实结束后释放；超过2秒的慢枚举也不能accept关窗后留下悬空访问。禁止强杀线程补救；验证完成与关闭交错及正常退出。
- W34错误快照与枚举结束异常不能当成功提交；保留旧数据并提示陈旧／失败，恢复重建基线。按采样代际丢弃跨暂停的在途结果，不仅看当前paused布尔值。明确手动刷新在暂停时执行一次但仍保持暂停、忙碌时不重入；与现有行为矩阵同步。结束等待期间GUI保持响应。
- W35只验证工具链兼容性，不重建功能或换UI；有可用稳定MSVC／Qt工具链才执行，不静默跳过GUI。
- 上述为源码核查发现的风险，尚未本轮动态复现；每票实施前先建立对应受控失败检查，不将推断冒充实际事故。

### W02：便携包
- 明确 Qt 及编译器运行库版本、第三方许可证声明和必要分发义务，不声称法律审查已完成。
- 包不依赖源码目录、构建目录、Raw或本机 Qt PATH，包含可审计包清单。
- 未装开发环境的 Windows 11 x64 下普通用户启动与核心流程通过；签名身份及公证不冒用厂商，自动更新不纳入。

### W03：导航与设置
- 只展示可工作页面，未来功能不放假按钮／空图表；保留 Processes默认入口。
- 保存窗口尺寸、刷新档位和显示偏好到独立本地应用目录；损坏配置／无写权限有安全默认值，写入失败不破坏旧配置。
- 单一采样调度，不因切页叠加 worker；键盘导航与缩放可用，不新建通用插件框架。

### W04—W08：系统性能与总览
- CPU按整机时间差采样，首样本不可计算；内存标明物理总量／可用／已用，不和工作集或提交量混用。
- 历史建议固定最近5分钟，过期自动淘汰；曲线不跨休眠／暂停或失败空隙连成伪数据，时间按单调时钟与真实间隔。
- W05核数／处理器组总量与归一化一致，P/E信息缺失显示未知，不按频率猜测；NUMA无数据明确说明。
- W06设备插拔、计数复位与权限不足处理；磁盘活动率测不到则不可用，不从吞吐推算。
- W07处理接口新增／删除／断链／计数复位；明确累计量起点，默认不包含名称／地址敏感信息的自动导出。
- W08复用已有来源，不另开重复采样；CPU／内存／磁盘／网络与主要进程可验证，能耗只在W23以后来源可信时接入，否则不显示伪值。

### W09—W12：进程扩展
- W09过滤范围标明字段，树无自循环，父进程缺失／退出／PID复用不错误关联；平铺／树模式下排序选择与安全操作一致。
- 只读详情包含可取得的名称、身份、路径等；拒绝访问明确，不要求读取其他进程秘密或完整环境变量。
- W10按累计 I/O差分与时间计算，新增身份重建基线；明确 Windows进程 I/O计数与物理磁盘活动区别。
- W11输出批准可执行的测量合同；区分累计量、速率、抓包与ETW事件，禁止包内容抓取／外传，权限不满足时提供明确不可用。
- W12仅聚合合同定义事件与目标身份，测试子进程流量和退出清理；权限不足不自动提权，不能把本机接口总量分配给进程。

### W13—W19：系统管理只读页与服务操作
- W13字段来源／单位／可用性明确；不扫描任意个人目录、读取密钥或连接厂商接口。
- W14先覆盖常见 Run注册表与启动文件夹，显示范围覆盖说明；不默认承诺所有启动机制、影响评分或启停。
- W15使用合法系统会话查询；只读，不注销／关闭其他用户进程，不暴露凭据。
- W16服务列表及状态刷新可测，与系统服务工具对照；服务PID不能直接作进程安全操作授权。
- W17仅启动／停止，不改启动类型、不删除、不批量；服务已处于目标状态可返回无变更，待定状态有限等待；拒绝危险系统服务或依赖影响无法可靠确认的目标，不仅名称黑名单。测试仅受控服务，创建测试服务另需权限授权。
- W18明确枚举来源覆盖，缺版本／容量不可用，不能用慢速全盘递归扫描填空；首版无卸载。
- W19仅卷容量，不递归分析文件夹、不删除；同一卷多挂载点避免重复，慢／离线网络卷不阻塞UI。

### W20—W25：未知功能的决策前置
- W20／W22／W24是**研究与决策交付票**，结束时须输出可执行的确定合同，不以“继续调查”关闭；若需仅用户可提供的证据则标阻塞。
- 来源记录官网声明、合法可访问原版观测、Windows公开API与独立设计；不使用补丁解锁、许可证或真实厂商授权服务。
- W20明确Connections是否网络连接列表或远程查看；若是远程，W21必须先修订或拆分协议／权限计划，禁止按猜测开工。本路线不预先建设远程服务、扫描器、抓包器或移动客户端。
- W22不新增内核驱动；无法安全测得功耗／温度时确定为不可用，列明频率是报告频率还是有效频率。
- W24推荐先一个有界CPU／内存基准，公开算法、固定时间上限、取消与环境字段；不复制不明原厂评分，不作为压力／稳定性测试，不默认写用户磁盘。具体指标与时长在合同票确认，不能模糊验收。
- W21／W23／W25各自包含 UI、真实采集／执行、错误反馈、可运行检查及本机对照；合同变化先更新票，不偷偷降级。

### W26—W27：Flight Recorder
- 不加商业授权门控；原版Pro标记是历史参考，不是本应用锁定条件。
- 独立版本化记录格式与扩展名，不宣称兼容原厂 `.tmogtrace`；先录已有系统数据，不记录进程路径、用户信息、网络载荷等敏感详情。
- 明确记录频率、时间单位、来源、可用性、缺样；建议最长30分钟／最大100MiB，达到任一上限停止并提示，设置可用且有硬上限；用户主动选择保存位置。
- 保存使用安全临时文件与原子替换策略，覆盖需确认，失败不损坏已有文件；临时文件仅本应用目录且清理规则明确。
- 打开文件作为不可信输入：大小／计数／版本／类型／时间单调性检查，未知必需版本拒绝，不执行或自动解压任何内容。
- 回放与实时采样分开，暂停／定位／退出回放不污染实时基线；有界内存，支持中途取消，不把缺样变0。

### W28—W31：外观、开销与交付
- W28系统主题与六种外观使用现有Qt能力，无新增主题库；文本／图线／选择／警告可分辨，主题持久化不破坏配置。
- W29主动启用自监控，不发送数据；展示本进程CPU／内存及采样耗时，避免自采样递归；记录闲置与负载场景，对照不启用状态，不虚构毫无开销。
- W30缺 ARM64环境不能凭x64模拟关闭，需原生构建与独立运行证据；不强制重做所有新增页面，但W31需对全功能逐页验收。
- W31验收所有Windows票及已知受限能力，区分构建／运行／自动检查／人工证据。未支持传感器／权限限制明示，硬件缺证据标未验证，不能宣称全功能等价。
- 签名凭据、发布账户和正式上传须另行授权；本票默认交付本地产物及发布说明，不默认上传公网或购买证书。
